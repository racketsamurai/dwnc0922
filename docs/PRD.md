# AI 글 피드백 코치 — 1페이지 PRD

## 1. 제품 개요

교수님께 보내는 결석 양해, 성적 조정, 서명 요청 등 민감한 요청 메일을 학생이 더 예의 바르고 목적에 맞게 작성하도록 돕는 웹 MVP다. 사용자는 메일 초안을 붙여넣고 요청 목적 등 조건을 입력한다. AI는 총평, 문장별 개선점, 바로 보낼 수 있는 수정본을 제공한다.

## 2. 목표 및 성공 기준

- 2시간 안에 로컬에서 작동하는 단일 사용자 데모를 완성한다.
- 사용자가 입력부터 결과 확인까지 1분 이내에 마친다.
- 결과의 수정본은 교수님에게 보낼 수 있을 만큼 공손한 한국어 메일 형식을 갖춘다.
- Gemini 응답 실패나 잘못된 JSON에도 사용자가 이해할 수 있는 오류 메시지를 보여준다.

## 3. 핵심 사용자와 시나리오

**사용자:** 교수님께 정중한 요청 메일을 보내야 하는 대학생.

**대표 흐름:** 학생이 메일 초안, 요청 목적, 맥락을 입력 → “피드백 받기”를 누름 → AI가 예의·명확성·요청 성취 가능성 관점에서 진단 → 총평과 문장별 제안을 검토 → 수정된 최종 메일을 복사해 사용한다.

## 4. 범위: 화면 2개

### 화면 ① 조건 입력 폼 (`/`)

- 글/메일 초안 붙여넣기 (필수, textarea)
- 요청 목적 선택: 결석 양해 / 성적 관련 요청 / 서명 요청 / 기타
- 추가 맥락 (선택): 수업명, 날짜, 사유 등
- 수신자 고정 안내: “교수님”
- “피드백 받기” 버튼, 유효성 검사, 처리 중 상태

### 화면 ② AI 결과 (`/result`)

- 총평 카드: 예의, 명확성, 설득력 관점의 짧은 진단
- 문장별 개선 제안 카드: 원문 문장, 문제점, 권장 수정 표현. 수정이 필요한 부분만 빨간색으로 강조
- 수정본 카드: 제목·인사·본문·맺음말을 포함한 완성 메일, 복사 버튼
- “다시 작성하기”로 입력 화면 복귀

## 5. API 및 응답 계약

`POST /api/feedback`은 입력값을 조합해 Gemini에 전달하고 다음 JSON만 반환한다.

```json
{
  "overallReview": "...",
  "sentenceSuggestions": [
    { "original": "...", "issue": "...", "suggestion": "..." }
  ],
  "revisedEmail": { "subject": "...", "body": "..." }
}
```

서버는 `GEMINI_API_KEY` 환경변수만 사용하며 키를 클라이언트에 노출하지 않는다. 시스템 프롬프트는 교수님 대상의 정중한 한국어, 사실을 새로 만들지 않음, 응답은 계약 JSON 외 텍스트를 포함하지 않음을 강제한다. 서버에서 JSON 파싱 및 구조 검증 후 클라이언트에 반환한다.

## 6. 디자인 원칙

- 흑백 기반의 단정하고 딱딱한 문서형 인터페이스
- 명확한 테두리, 낮은 장식성, 충분한 여백
- 수정이 필요한 문구·경고만 빨간색 포인트 사용
- 모바일과 데스크톱에서 읽기 쉬운 단일 열 레이아웃

## 7. 기술 스택

- Next.js (App Router), TypeScript
- Gemini API (`@google/generative-ai` 또는 Gemini REST API)
- CSS Modules 또는 `globals.css` 기반의 최소 스타일링

## 8. Non-goals

- 로그인·회원가입 및 사용자 계정
- 결과/입력값 저장, 히스토리, 데이터베이스
- 파일 업로드, 이메일 발송, 교수님 연락처 관리
- 다국어 지원, 협업, 결제
- 피드백 품질의 자동 평가·학습 및 관리자 화면
- 실제 성적 이의제기·결석 승인 등 행정 절차의 자동 처리

## 9. 2시간 구현 순서

1. Next.js 기본 프로젝트와 환경변수 예시 구성
2. 입력 폼 및 결과 화면의 정적 UI 구현
3. Gemini Route Handler·프롬프트·JSON 파싱/검증 구현
4. API 연결, 로딩/오류 상태, 복사 기능 확인
5. 1~2개 한국어 메일 예시로 수동 점검

## 10. 수용 기준

- 초안 없이 제출할 수 없고, 필수 값 오류가 명확하다.
- 정상 입력 시 세 종류의 결과 카드가 표시된다.
- 수정본에 공손한 인사·요청·감사·맺음말이 포함된다.
- API 키는 브라우저 번들, UI, API 응답에 노출되지 않는다.
- Gemini가 계약 밖 형식으로 응답하면 안전하게 오류 처리한다.
